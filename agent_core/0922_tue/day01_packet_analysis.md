# Day 01 · 네트워크 패킷 분석

## 1. Wireshark란?

Wireshark는 네트워크를 통해 오가는 패킷을 캡처하고 분석하는 프로그램이다. 보안 담당자는 패킷을 분석해 의심스러운 통신이나 비정상적인 네트워크 활동을 확인할 수 있다.

## 2. 패킷(Packet)이란?

패킷은 네트워크에서 데이터를 주고받을 때 전송하기 좋게 나눈 데이터 단위이다.

## 3. Npcap이란?

Npcap은 Windows에서 네트워크 패킷을 캡처할 수 있도록 도와주는 프로그램이다. Wireshark가 패킷을 수집할 때 사용한다.

## 4. 설치 확인

- Wireshark 설치: 완료
- 네트워크 인터페이스 목록: 표시 확인
- Npcap 설치 여부: 추가 확인 필요

## 5. 파이프(Pipe) 실습

실행한 명령어:

```bash
tasklist | grep Code
```

실행 결과: `Code.exe`가 포함된 프로세스 목록을 확인했다.

파이프(`|`)는 앞 명령어의 출력을 뒤 명령어에 전달한다. `grep Code`는 전달받은 내용에서 `Code`가 포함된 줄을 찾는다.
