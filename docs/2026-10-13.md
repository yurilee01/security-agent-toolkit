## 오늘 새로 쓴 명령
- `cat`: 파일 내용을 화면에 보여 주는 명령
- `grep`: 원하는 글자가 들어 있는 줄을 찾는 명령

## 오늘 쓴 옵션
- `-n`: 찾은 줄에 줄 번호를 붙인다.
- `-c`: 조건에 맞는 줄의 개수를 보여 준다.

## 찾아보고 알게 된 것
보안 담당자는 로그에서 로그인 실패나 오류가 발생한 기록을 빠르게 찾기 위해 grep을 사용한다.

## 막힌 것
파일 이름을 sample.log로 수정하는 과정에서 확장자 .txt를 제거했다.

## 다음에 확인할 것
cat과 grep 명령어를 다시 연습하기

### 실습 결과
`grep -n "로그인 실패" network_zt/sample.log` 명령어로 로그인 실패 기록이 2번 줄과 5번 줄에 있는 것을 확인했다.

`grep -c "로그인 실패" network_zt/sample.log` 명령어의 결과는 `2`였다. 이를 통해 로그에서 특정 문구가 포함된 줄을 찾고 개수를 확인하는 방법을 익혔다.
